# 功能二：PCB 布局建议

用户在 Layout 阶段拿不确定的摆放来问，比如"U1 放哪合适"、"这几个电容怎么摆"、"这样布局行不行"。这时还没有确定的走线，需要依据**原理图的连接关系**给相对位置建议。

## 先确认状态

问清楚现在是哪个阶段：

- **还没摆**（只有原理图）→ 给绝对建议：主元件定在哪、各外围往哪边放
- **摆了没画线** → 先读现有布局，在此基础上给调整建议，不要推翻重来
- **画了线** → 那是审查（功能一），不是布局建议；顺便可以给布线优化意见

一步拿全事实：

```bash
python scripts/placement_brief.py --project P --ref U1
```

它输出：PCB 各文档的阶段（还没摆 / 摆了没画线 / 已有走线）、候选主元件排序
（邻居网络数 + 引脚数）、机械约束器件清单、以及指定位号的**信号邻居强度**
（共享 net 越多越该靠近；电源/地这类挂几十颗器件的 net 已剔除，否则所有器件都"最该靠近"）。

底层命令（要手查时用）：

```bash
easyeda pcb list --project P --doc D --include-bbox    # 已有器件的坐标、层、旋转
easyeda pcb track-list --project P --doc D             # 有没有走线
```

`track-list` 返回 0 条线就是"摆了没画"。

## 找主元件

布局建议的第一件事是确定「谁围着谁转」。判据按优先级：

1. 引脚最多的 IC（`sch read` 的 `pins` 数组长度最大）
2. 有最多外围器件直连的器件（数每个 net 上挂了几个器件，取度数最高的）
3. 机械约束优先：连接器（CN*）、按键（SW*）、指示灯（LED*）的位置由外壳决定，反过来约束其他一切

把这三条都想一遍再给建议。有的板子没有明显主元件——用户做的是分散的多模块板，那就要拆成几个子区域分别给建议。

## 从原理图取连接强度

没有 netlist 文件也没关系，`sch read` 的 `components[].pins[].net` 就够用了。按 net 把器件归组，就得到"谁和谁必须靠得近"：

- 同一个 net 上的器件，物理距离越短越好——尤其是高频、大电流、模拟信号
- 两个器件共享的 net 越多，越应该靠近
- 一个器件通过很多个 net 连到主元件 → 是主元件的外围，贴着主元件摆

**注意跨页**：同一网络可能跨页，`sch read` 单页拿不全。多页工程要把所有页读一遍再归组。本类工程就有 `MOTOR_DRIVE1` 这类网络从控制页连到强电页的情况。

## 摆放原则

按这个顺序给建议，从强约束到弱约束：

1. **机械约束**：连接器、按键、指示灯、天线开窗——位置由外壳和用户操作决定，先定死
2. **主板分区**：强电区、弱电区、模拟区、高频区，中间留沟槽或保持足够的爬电距离。强电和弱电的器件不能交错摆
3. **核心器件**：主 IC 放在中间偏一侧，让它的所有外围都能就近展开
4. **去耦电容**：每个电源引脚一个，贴着引脚放，电容的接地端要通过过孔直接下到地平面。优先级比"整齐好看"高得多
5. **晶振**：紧贴 MCU 的 OSC 引脚，走线尽量短，下面铺地或挖空按设计意图保持一致的层
6. **其它外围**：按信号方向排布，输入在一边输出在另一边，避免来回穿越

## 走线建议

布局建议里顺带给的走线方向，说清这几件事：

- **哪条线必须短**：高频时钟、晶振、USB 差分、开关电源反馈、大电流路径
- **哪条线必须宽**：电源主干、大电流、地线。给个大致数字比"加宽"有用——1oz 铜、温升 10℃ 时，1A 大约 20mil
- **哪几条不能平行走**：强电与弱电、开关节点与反馈网络、时钟与模拟信号
- **换层要在哪里**：信号换层处补地过孔，电源换层处加过孔阵列
- **地怎么处理**：数字地和模拟地的分割或单点连接位置，铺铜优先级

**不要给具体坐标。** 用户要的是"往哪个方向、离多远、为什么"，不是替你摆。给坐标反而限制了用户的发挥，而且不同封装尺寸下坐标会失效。

## 相对位置的表达

用"相对主元件"来描述，不用绝对坐标：

- ✅ "U1 的 VBAT 引脚旁 100mil 内放 C3，接地端朝外"
- ✅ "X1 紧贴 U1 的 OSC_IN/OSC_OUT（PIN5/PIN6），走线总长不超过 200mil"
- ❌ "把 C3 移到 (1200, -800)"

距离用 mil（PCB 命令基本都是 mil）。需要换算时 100 mil = 2.54 mm。

## 输出格式

```
## 一句话
这块板的核心是 U1（STM32F103，48 脚），所有布局围绕它展开。

## 主元件与分块
- 主：U1，放板子中偏左
- 强电区（左上）：U22、K1、R23 等
- 弱电区（右）：U1 及其全部外围

## 摆放建议
| 器件 | 相对位置 | 理由 |
|---|---|---|
| C3, C4, C5 | U1 的 VCC 引脚旁 100mil 内 | 每个电源脚一个去耦 |
| X1 | U1 的 OSC 引脚旁，走线 <200mil | 晶振走线长了容易起振困难 |

## 走线要点
- 3V3 主干：从 U1 的 VDD 引出，线宽 ≥40mil
- 晶振两线：尽量短、等长，下方保持无铜（两层都要）
- 强电与弱电：U22 光耦做隔离，跨隔离带不要走其它线

## 需要你确认的
- 外壳尺寸和接口位置？
- 大电流路径的额定电流多少？
```

「需要你确认的」这一节很重要——布局有大量信息在原理图里，比如外壳尺寸、装配方向、散热要求，这些只能问用户，不能假设。

## 常见错误

- 直接给坐标 → 用户的封装尺寸、板框都不一样，坐标没意义
- 只说"要靠近"不说"为什么" → 用户下次遇到类似情况还是不会
- 忽略机械约束 → 连接器和按键位置是外壳定的，跟电气优化无关，优先级最高
- 忽略跨页网络 → 以为某个模块孤立，实际它和主元件有跨页连接
- 建议里掺进审查结论 → "这里有问题"是功能一的活，布局建议只谈摆放和走线
